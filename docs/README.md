# 📑 Documentação Técnica ( docs/ )

## 📌 Introdução

A pasta `docs/` é o núcleo de documentação técnica, modelagem de software e design de experiência do usuário (UI/UX) do módulo **AgendaContatos**.

Em um projeto orientado a objetos com foco em persistência de dados local e interface gráfica, a documentação visual e arquitetural é indispensável para alinhar a visão técnica da equipe **SDAMK Studios**. Este diretório reúne desde o levantamento inicial de telas (wireframes) e fluxo de navegação até diagramas formais de UML e materiais de apresentação acadêmica utilizados na defesa do projeto no **IFCE Campus Maranguape**.

---

## 📁 Estrutura de Diretórios

```text
docs/
├── README.md                   # Documentação e guia do diretório de documentos
├── diagrams/                   # Diagramas explicativos do fluxo funcional do sistema
├── presentations/              # Apresentações em slides e defesas acadêmicas
├── ui-ux/                      # Projeto visual de interface e experiência do usuário
│   ├── mockups/                # Designs de alta fidelidade com visual final das telas
│   ├── prototypes/             # Protótipos interativos para simulação de uso
│   └── wireframes/             # Esboços estruturais e leiaute inicial das telas
└── uml/                        # Diagramas UML (Casos de Uso, Classes, Sequência, etc.)
