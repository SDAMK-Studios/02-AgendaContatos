# 🛠️ Materiais de Apoio e Suporte ( support/ )

## 📌 Introdução

A pasta `support/` atua como um repositório auxiliar de conhecimento, agrupando documentações complementares, referências bibliográficas, tutoriais de uso e registros em vídeo desenvolvidos pela equipe **SDAMK Studios**.

O objetivo deste diretório é fornecer todo o suporte necessário tanto para novos desenvolvedores que venham a colaborar com o projeto quanto para usuários e avaliadores acadêmicos do **IFCE Campus Maranguape**, garantindo fácil acesso às instruções de configuração, guias de execução e demonstrações visuais do funcionamento do módulo.

---

```text
support/

├── tutorials/                  # Guias passo a passo para configuração e uso da aplicação
└── videos/                     # Demonstrações em vídeo, gravações de uso e apresentações
