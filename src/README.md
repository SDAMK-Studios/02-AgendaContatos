# 💻 Código-Fonte ( src/ )

## 📌 Introdução

A pasta `src/` (do inglês *source*) é o diretório principal que centraliza todo o código-fonte em **Java** da aplicação **AgendaContatos**.

Neste espaço residem as implementações orientadas a objetos responsáveis por dar vida às funcionalidades do sistema de gestão de contatos. A organização do código segue boas práticas de arquitetura em camadas (separação de responsabilidades entre Interface de Usuário, Regras de Negócio/Controles, Objetos de Transferência de Dados e Camada de Persistência/DAO), permitindo que a aplicação execute com eficiência as operações **CRUD** e interaja com o banco de dados **MySQL** de forma segura, modular e coesa.
